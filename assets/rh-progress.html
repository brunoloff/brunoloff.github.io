    Each square is 0.1% of the 17.4 million lines of Lean, grouped by chapter; it fills in as the files compile. The build runs the claimed proof through Lean’s kernel on a cloud machine and publishes progress every 5 minutes. A finished build only means something together with the last two steps: the main theorems must rely on nothing beyond Lean’s three standard axioms, and a kernel replay re-checks every compiled declaration to rule out metaprogramming tricks. This uses Lean’s own kernel; it does not rule out a bug in that kernel.
